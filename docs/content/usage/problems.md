`mosty check` が検出する問題の種類と、直し方をまとめます。
括弧内は、JSON 形式で出力したときの `kind` の値です。

---

## 🔀 学生証番号の不一致（`id_mismatch`）

```
最終成績!C4 (1234003 山田 一郎) -> 課題!E7 (1234004 佐藤 次郎): student id mismatch
```

参照元の行の学生と、参照先の行の学生が異なります。いわゆる「1 行ずれ」です。

- **よくある原因**: 参照先のシートで行を挿入・削除した、数式をコピーしたときに参照がずれた、など。
- **直し方**: 参照元の数式が、同じ学生の行を指すように直します。同じ列で連続して報告されている場合は、途中から行がずれていることが多いので、ずれ始めた行を探してください。

氏名のセルが別の行を参照している場合も、この問題として報告します。
学生証番号と氏名を別々に名簿から参照していて、片方だけずれている場合に見つかります。

---

## 📊 複数の学生にまたがる範囲の参照（`multi_student_range`）

```
最終成績!H3 (1234002 京産 花子) -> 課題!E4:E8: range spans multiple students
```

ある学生の行から、複数の学生の行を含む範囲を参照しています（`=SUM(課題!E4:E8)`、`=MAX(試験!C:C)` など）。

- **よくある原因**: 1 人分の範囲のつもりで、複数行の範囲を書いてしまった。
- **直し方**: その学生の行だけを参照するように直します。全員の平均などを意図している場合は、学生の行ではない集計の行で計算するか、検索関数（`VLOOKUP` など）を使ってください。

---

## 👯 学生証番号の重複（`duplicated_id`）

```
試験: duplicated student id 1234003 at 試験!A4, 試験!A5
```

同じシートの学生の範囲に、同じ学生証番号が複数あります。

- **よくある原因**: 学生を追加・削除するときに、学生証番号を書き間違えた、または消し忘れた。
- **直し方**: 重複している行を確認し、正しい学生証番号に直すか、不要な行を削除します。

---

## 🆕 設定ファイルにないシート（`unknown_sheet`）

```
小テスト: sheet is not in the config file (run `mosty init` again)
```

設定ファイルを作った後に、Excel ファイルにシートが追加されました。このシートは検証されていません。

- **直し方**: `mosty init -f` で設定ファイルを作り直すか、設定ファイルにシートを書き足します。

---

## 🗑️ Excel ファイルにないシート（`missing_sheet`）

```
旧課題: sheet is not in the workbook
```

設定ファイルに書かれたシートが、Excel ファイルにありません。シートが削除されたか、名前が変わりました。

- **直し方**: `mosty init -f` で設定ファイルを作り直すか、設定ファイルのシート名を直します。

---

## 🚪 学生の範囲の外にある学生証番号（`id_outside_table`）

```
名簿!A7: student id 1234006 is outside the student table
```

設定ファイルに書かれた学生の範囲（`start_row` から `end_row`）の外に、学生証番号があります。

- **よくある原因**: 設定ファイルを作った後に、表の最後に学生を追加した。
- **直し方**: 設定ファイルの `start_row` または `end_row` を直すか、`mosty init -f` で作り直します。

---

## ℹ️ 問題としては報告しないもの

次のものは、問題として報告せず、ログ（標準エラー出力）に出します。

| レベル | 内容 |
|---|---|
| WARN | 学生証番号の数式の計算結果が保存されていない（Excel で開いて保存し直してください）。 |
| INFO | 学生の行から、学生の行ではない行（空行、見出しなど）を参照している。 |
| INFO | `INDIRECT`、`OFFSET`、名前付き範囲など、参照先を決められないため検証を飛ばした。 |

INFO のログは、`-l info` を指定すると表示されます。
